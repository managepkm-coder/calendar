# 교대 근무표 (camcar-check)

**주 → 야 → 비 → 휴** 4일 주기 교대 근무표를 보여주는 웹 앱입니다.
광고도, 사용기간 제한도, 서버도 없습니다. 근무는 기준일로부터 계산되므로 과거·미래 어느 달이든 볼 수 있습니다.

## 쓰는 법

1. **GitHub Pages 켜기** — 저장소 `Settings → Pages → Source`를 **GitHub Actions**로 지정합니다.
   `main` 브랜치에 푸시되면 자동 배포되고 `https://managepkm-coder.github.io/calendar/` 로 열립니다.
2. **폰에서 홈 화면에 추가**
   - iOS Safari: 공유 → *홈 화면에 추가*
   - Android Chrome: 메뉴 → *홈 화면에 추가*
   앱처럼 전체화면으로 열리고, 오프라인에서도 동작합니다.
3. **내 조 맞추기** — ⚙ 를 눌러 **오늘의 근무**를 고르면 나머지 날짜가 전부 맞춰집니다.

## 기능

| | |
|---|---|
| 달 이동 | `‹` `›` 또는 좌우 스와이프 |
| 오늘로 | `⟳` |
| 하루만 바꾸기 | 날짜를 탭 → 주/야/비/휴/연차 선택 (교대·연차용, 파란 테두리로 표시) |
| 공휴일 | 대체공휴일 포함해 날짜 옆에 표시 |
| 다크 모드 | 기기 설정을 따라감 |

설정과 수동 지정은 브라우저에 저장됩니다(localStorage). 서버로 나가는 데이터는 없습니다.

## 홈 화면 위젯

잠금 해제 없이 오늘 근무를 바로 보려면 [`widget/`](widget/) 을 보세요.

- **iOS** — Scriptable 스크립트 한 개. 빌드도 개발자 계정도 필요 없습니다.
- **Android** — GitHub Actions가 APK를 빌드해 줍니다. 폰만으로 설치까지 가능합니다.

웹앱과 같은 계산식을 쓰므로 표시 결과가 항상 일치합니다.

## 근무 주기를 고치려면

`app.js` 맨 위:

```js
const CYCLE  = [주, 야, 비, 휴];          // 주기 순서
const ANCHOR = Date.UTC(2026, 7, 30);     // 이 날이 CYCLE[0] (= 주간)
```

주기 자체가 다르면(예: 3조 2교대) `CYCLE` 배열을 바꾸고, `app.js`의 `% 4` 를 `% CYCLE.length` 로 바꾸면 됩니다.

## 공휴일 데이터

`holidays.js` 에 표로 관리합니다. 설날·추석·부처님오신날은 음력 기반이라 계산 대신 직접 적어둡니다.
**2025~2026년은 확정 데이터, 2027년은 추정치**이므로 연말에 관보 확정 후 확인하세요. 한 줄씩 추가하면 됩니다.
