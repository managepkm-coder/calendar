## 알아둔 것

### 캘린더 연동이 "안 되는" 것처럼 보일 때

앱에는 **인터넷 권한이 없습니다.** 폰 캘린더에 일정을 써넣으면 계정이 구글일 때
**안드로이드가 알아서 올립니다.** 그래서 문제는 거의 항상 앱이 아니라 그 바깥입니다.

실제로 한 번 겪은 경로: 일정은 `가족` 캘린더(구글 가족 그룹, 계정은 사용자 Gmail)에
제대로 들어가 있었는데 **삼성 캘린더 앱에서 그 캘린더 체크가 꺼져 있어** 아무 데도 안 보였습니다.

진단 순서:

1. ⚙ 세 번째 줄이 `캘린더 자동 연동 · 켜짐` 인지 → 아니면 연동이 안 켜진 것
2. 눌러서 `지금 다시 내보내기 (마지막 …)` 확인 → `아직 내보내지 않음` 이면 쓰기 실패
3. 눌렀을 때 토스트의 **숫자** — 90 안팎이면 정상, `0`/`-1` 이면 앱 문제
4. 폰 캘린더 앱에서 그 캘린더 **체크가 켜져 있는지**

`마지막 …` 날짜가 찍혀 있어도 **0개를 넣었을 수 있습니다.** 날짜는 `export` 가 오류 없이
끝나기만 하면 기록되므로, 실제로 몇 개 들어갔는지는 숫자로만 알 수 있습니다.

내보내기는 **지우고 다시 넣습니다.** 구글 캘린더에서 그 일정에 알림이나 메모를 붙여두면
다음 동기화 때 사라집니다.

### CI 가 앱 코드와 무관하게 깨질 때

`android-actions/setup-android` 는 `packages` 를 안 적으면 기본값이 `tools platform-tools` 인데,
구글이 **`tools` 를 SDK 저장소에서 내렸습니다.** 그래서 앱을 한 줄도 컴파일하기 전에
`Failed to find package 'tools'` 로 죽습니다. v3·v4·main 모두 기본값이 같아 버전을 올려도 똑같습니다.
`.github/workflows/android.yml` 에서 `packages: 'platform-tools'` 로 못박아 두었습니다.

### 폰에서 APK 다운로드가 안 될 때

릴리스 링크 자체는 정상입니다(로그인 없이 200으로 받아집니다). 막히는 건 폰 쪽입니다:

- 카카오톡·클로드 등 **앱 내부 브라우저**는 다운로드를 못 합니다 → 주소를 복사해 크롬·삼성인터넷에
- 크롬이 `이 파일 형식은 기기에 해를 끼칠 수 있습니다` 로 막습니다 → `계속` 을 눌러야 내려옵니다
- GitHub 가 드물게 APK 대신 HTML 오류 페이지를 줍니다 → 받은 파일이 몇백 KB 면 다시 받으세요

### RemoteViews 에는 아무 뷰나 못 넣는다

위젯 레이아웃은 `@RemoteView` 가 붙은 클래스만 펼칠 수 있습니다. 평범한 `View` 를 넣으면
**위젯이 통째로 안 뜹니다.** 그래서 위젯의 구분선은 `View` 가 아니라 `LinearLayout` 입니다.
앱 화면은 일반 화면이라 `View` 를 씁니다.

### MATCH_PARENT 칸은 자기 높이를 말하지 못한다

v3.9 의 "화면에 들어가면 꽉 채우고 넘치면 스크롤" 이 **실제로는 동작하지 않았습니다.**
날짜 칸을 `MATCH_PARENT` 높이로 두면 칸은 "내 내용이 이만큼 필요하다"가 아니라
"주어진 만큼"을 답합니다. 그래서 주 줄이 필요한 높이를 알릴 수 없었고, 달력은 늘
화면 높이를 주 수로 나눈 값에 고정됐습니다. 스크롤은 한 번도 켜지지 않았고,
칸을 넘는 메모는 조용히 잘렸습니다.

v4.1 부터 **주 줄이 자기 칸 일곱 개를 직접 재서**(`rowHeight`) 가장 높은 칸만큼 높이를 잡습니다.
`MainActivity.rowHeight` / `cellWidthPx` 를 건드릴 때 이 함정을 기억하세요.

### 위젯은 자기 크기를 재지 못한다

런처가 알려주는 `OPTION_APPWIDGET_MIN_HEIGHT` 로 가늠하는 수밖에 없습니다
(`ShiftWidget.hasRoomForMemo`). 머리글·요일 줄을 빼고 6주로 나눠 메모 한 줄이 들어가면 보여줍니다.
글자 크기를 바꾸면 `ROW_FOR_MEMO_DP` 도 같이 손봐야 합니다.

### 색은 한 곳에만

근무 색은 `res/values/colors.xml` 의 `shift_*` 에만 있습니다. 위젯 배지 drawable(`badge_*.xml`)과
앱 화면(`Palette.barColor`)이 같은 값을 가리키므로 한쪽만 달라질 일이 없습니다.
`Palette.exportRgb` 는 구글 캘린더로 내보낼 때 쓰는 별개의 값이니 **색을 바꾸면 이쪽도 같이** 보세요.

## 남은 일

- **웹앱과 iOS 는 아직 4일 주기가 코드에 박혀 있습니다.** 안드로이드만 v4.0 부터 사용자가 패턴을
  정할 수 있습니다. 기본 4일 주기가 아닌 패턴을 쓰면 세 화면이 서로 다르게 나옵니다.
  (`app.js` 의 `CYCLE`/`ANCHOR`, `widget/ios/shift-widget.js` 의 같은 이름)
- **구글 드라이브에서 가져오기** — 무엇을 가져올지 정하지 못해 멈춰 있습니다.
  인터넷 권한도 의존성도 없이 `ACTION_OPEN_DOCUMENT`(안드로이드 파일 선택기)만으로 됩니다.
  선택기에 드라이브가 그대로 나오고, 드라이브 앱이 내용을 건네줍니다.
  같은 방식으로 **설정 백업/복원**도 만들 수 있습니다 — 폰을 바꾸면 근무 패턴·메모·알람이
  전부 날아가는 문제가 이걸로 풀립니다.
- **위젯 메모는 한 줄 + `+N`** 입니다. 앱은 여러 줄을 보여줍니다.
- 서명 키(`keystore/personal.jks`)가 공개 저장소에 있습니다. 개인 사이드로드 전용이며,
  배포할 앱이라면 별도 키가 필요합니다 (`widget/README.md` 참고).
